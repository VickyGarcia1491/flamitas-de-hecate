Datos de Flamitas

1. Recuperar los datos anteriores

Abrí esta página desde la misma dirección local y en el mismo navegador donde usabas la tienda. No borres los datos del navegador.

El archivo incluye productos, stock, pedidos y consultas. Las cuentas antiguas deberán registrarse nuevamente: las contraseñas locales no se exportan.

2. Importar en la web nueva

Iniciá sesión como administradora en la web de Render. Seleccioná el archivo anterior, revisá el resumen e importalo antes de recibir pedidos. Solo se permite una importación inicial.



Respaldo y consultas
El respaldo comercial contiene catálogo, pedidos, stock y consultas. Para recuperar también cuentas y sesiones necesitás un respaldo completo de PostgreSQL.
